Get-FileHash .\VoiceCloneStudio-1.0.0.exe -Algorithm SHA256

Why is it 1.78 GB?

  • NVIDIA CUDA + PyTorch libraries — 3.8 GB of the 4.5 GB unpacked
  • A bundled Python runtime, so you install nothing
  • The speech model wrapper and a local web interface

The AI voice model itself is a separate 2.5 GB download on first launch.

Questions

Does it need internet?
Once, to fetch the voice model. Fully offline after that.
Is my audio uploaded anywhere?
No. Recording, cloning and generation all happen on your machine.
Do I need a graphics card?
No, but without one expect many minutes per paragraph instead of seconds.
How do I uninstall it?
Delete the folder. Nothing is written elsewhere.

If something goes wrong

"Windows protected your PC"
Expected — the app is unsigned. More info → Run anyway.
"Port 8000 is already in use"
Another program has it. Close that program, then reopen the app.
A yellow "running on CPU" banner
No usable GPU was found. It still works, just slowly.
Output mumbles or skips words
Almost always the reference clip. Use 10–20 seconds, recorded dry and close to the mic.

Specifications

  • Output: MP3, 24 kHz mono
  • Reference clip: 2–60 seconds (10–20 s is best)
  • Script limit: 60,000 characters per job
  • One job at a time — the queue is shared across everyone on your network

Using it from other devices

While the app is open, anyone on the same Wi-Fi can use it through your machine's browser — no install on their side. The app shows the address to share.

Your computer does the work, so it needs to stay awake.
