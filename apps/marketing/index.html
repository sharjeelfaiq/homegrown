STARTUP & QUEUE

Model loading comes before generation.

On first use, the packaged app downloads the model and shows startup progress while it initializes. Clone voice and Generate remain disabled until ready. Jobs run one at a time; additional requests queue, and long scripts report chunk progress.

Setup, safety, and common questions

What happens on first run?

The packaged Windows app extracts, then its local backend initializes Qwen3-TTS. The first launch downloads the model with progress. Startup can take time; Studio keeps creation and generation controls disabled until the model reports ready.

What hardware do I need?

Use 64-bit Windows 10/11 and allow about 8 GB free storage. NVIDIA with CUDA drivers is recommended. CPU fallback is available but may take many minutes per generation. No Python or Node is needed to run the packaged app.

Why does Windows warn me?

The release is unsigned, so SmartScreen can show “Windows protected your PC.” The Google Drive download page may also say it cannot scan a large file. Review the source you received; if you trust it, choose More info, then Run anyway.

Is it private?

Homegrown has no account or hosted voice service. Your model, audio, presets, and history remain on the machine. The local API has no authentication, so do not expose the app to an untrusted network.

Can I use any voice?

No. Only clone voices you own or have permission to use.
