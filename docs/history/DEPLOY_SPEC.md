# Historical deployment proposal (archived)

Homegrown previously considered a Vercel + RunPod deployment. That proposal
was not implemented and is not compatible with the current local Windows
workflow. This archive intentionally contains no executable steps,
environment-variable guidance, or claims about current behaviour.

Use [README.md](../../README.md), [workflow.md](../workflow.md), and
[BUILD.md](../BUILD.md) for supported usage. Source code is authoritative when
documentation and implementation differ.
